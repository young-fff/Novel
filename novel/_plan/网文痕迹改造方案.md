# 网文痕迹改造方案

> 制定：2026-08-13。基础：原稿以网文写法为底——接连不断的章末钩子、男频剧情与文字、每4000字一个情绪落点的节奏。本方案只拆痕迹、不伤骨架。
> 总判断：网文基因里有些是资产，有些是负债。区别标准：**资产=支撑强冲突强张力的类型容器；负债=让人物变扁、让主题变浅的设计。**

## 〇、保留清单（不动）

1. **类型容器**：末世+围城+博弈的强冲突骨架（作者审美=文学标准筛类型，猎魔人/金庸为证）
2. **"恐惧打断争斗"等结构性原则**（文学同样需要，保留）
3. **单字章名体系**（借/拾/秤/雪——出版辨识度资产，并章后降为节名）
4. **卷末钩子**：每卷仅一个、且须余味型（ch46 执事翻教义/ch70 已是标杆；ch22"铁脊点名"检查语气）

## 一、改造清单（8项）

### 1. 章末钩子密度（全书88个）
- **现状**：章节清单每章必标"伏笔/钩子"；部分钩子为凑字数后补（vol3 审稿记录：ch49/57 补钩子达标）
- **方案**：并章后每章只留一个收束点；钩子分三档——a) 删（凑字数型）；b) 悬念降余味（"雪越下越大了"式，保留）；c) 保留为章内推进力（不置章末）。标准：**章末让读者合书，而不是急着翻页**
- **落点**：并章环节统一处理（正文修订最后一步）

### 2. 爽文高潮写法
- **现状**：ch45 路线图拍桌、ch66 重新定价、v4 三楔——"当众打脸+全场震惊"的爽感结构
- **方案**：事件不动，爽点改代价点——妃飞拍图的手在抖；理事们的沉默是后怕不是敬畏；每赢一步立刻让出一寸。标杆句：ch46 已有的"他掀了棋盘，但他还站在棋盘上"——删围观者震惊镜头，留当事人自己的恐惧
- **落点**：v2 ch45、v3 ch66、v4 ch75-78

### 3. 男频关系结构
- **现状**：文档"其余四人以不同深度留下"（已改）；正文侧顾晚/林昭/叶生三条线或暧昧或依附
- **方案**：文档已去标签化；正文阶段——林昭线坐实为同盟交易（她的逻辑始终是"你也是件货，我也是，所以结盟"），叶生线坐实为同伴信任，顾晚线强调她的主动选择。删一切"被征服/心动"式微表情描写
- **落点**：v2 ch28-34（林昭）、ch27-31（叶生）、v1 ch8 起（顾晚）

### 4. 金手指感
- **现状**：免疫+名牌大学+四年满级生存经验=男频男主标准配置
- **方案**：不动设定，动比重——东滩之责已落地；免疫只带来麻烦不带来好处（原文已基本如此，守住）；"满级"感靠压缩信息灌入段削弱（v1 ch1 人物卡式大段）
- **落点**：v1 ch1 优先

### 5. "杀伐果断"美学
- **现状**：ch10 处决、ch20 弃人；章节清单 ch20 情绪基调词竟是"活下来的残酷喜悦"
- **方案**：ch10 把"狠"改写成"罪"（处决后接三分钟闪回第一拍）；ch20 情绪基调改"恐惧+侥幸+不敢回想"；删所有"他不再犹豫"类表述
- **落点**：v1 ch10、ch20-21

### 6. 节奏与情绪落点过密
- **现状**：每4000字一个情绪落点/小高潮（章节清单的设计使然）
- **方案**：并章自然解决；章内2-3个推进点+1个收束点
- **落点**：并章环节

### 7. 视角轮换的运营化
- **现状**："避免连续妃飞视角超3章"=网文防疲劳规则
- **方案**：改为文学原则——视角跟"谁的盲区此刻最疼"走，不设轮换上限；顾晚/沈青章本就是全书最好视角章，保留
- **落点**：全卷

### 8. 男频词汇层
- **现状**（grep 证据，全88章污染度低）：红颜1 / 猎物1 / 冷冽2 / 嘴角5 / 冷笑6
- **方案**：通扫清理这15处——"冷笑"按角色保留沈砺少数几处（属其语言系统），删叙事者与妃飞的
- **落点**：全卷通扫

## 二、执行原则

1. **拆钩子不做减法做置换**：悬念→余味
2. **爽点→代价点**：事件保留，写法改写
3. **对仗→杂质**：镜像结构里塞进偶然与不适
4. 所有改造以**叙事者伦理**为总纲：删"全场震惊"，留"一个人的后怕"
