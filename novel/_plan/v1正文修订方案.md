# 第1卷正文修订方案（试点卷）

> 制定：2026-08-13。依据：《设定总文档v2_修改稿》《网文痕迹改造方案》《第1卷大纲出版化修订注记》。v1 是全文试点的样板卷——v1 的手感定了，v2-v4 照此推进。
> 修订顺序：落点+压缩并行 → 全卷通扫 → 压缩完成后并章定稿。章号在并章前保持原样。
> **执行状态（2026-08-13 第一轮完成）**：第2/4/5/6节全部落地（22章过稿+插页2篇+并章10章，成品在 `novel/v1_merged/`）；第1节并章映射已执行；深度逐行压缩与衔接润色待后续轮次。

## 0. 总则

- 叙事者伦理：叙事者只给事实、感官与动作，不下判断、不点题（每章改完过自查清单）
- 读者拼图：删旁白式设定讲解；每个设定只解释到"当下够用"
- 目标文风：冷峻短句、动词驱动；删"全场震惊"，留"一个人的后怕"
- **字数目标（2026-08-13 定稿·温和压缩）**：全书由约38-40万字压缩至 **30-32万字**（-15~20%）；压缩与落点修订并行，每章按压缩清单过一遍
- **分章目标**：压缩后并章，全书 **40-44章**（2并1为主、个别3并1、刻意短章保留），章均约7000-8000字；最终章数在并章阶段按实际字数定稿

## 1.5 压缩清单与保护清单（温和压缩·每章过一遍）

**压缩来源（全书合计约4-7万字，-15~20%）**：

| 类别 | 预估 | 处理 |
|---|---|---|
| 章末钩子句/悬念铺垫 | 每章100-300字 | 直接删（并章前先删） |
| 信息灌入段（人物卡/设定卡） | 1-1.5万字 | 拆散保留必要碎片，其余后移或删 |
| AI味翻译句/升华排比 | 0.8-1.5万字 | 删或换成具体动作 |
| 爽文围观镜头 | 0.5-1万字 | 删，留当事人反应 |
| 冗余环境底噪句 | 0.3-0.5万 | 纪律性环境句留一半 |
| 对白解释性复述 | 0.3-0.5万 | 删 |

**保护清单（压缩时不许碰）**：顾晚/沈青视角章核心段；环境散文感段落（李娟式荒野书写）；三拍式闪回全文；关键对白（"来不及了"、沈青"我图的就是他不该被标价"类）；留白章 ch85；终章 ch88；单字章名体系。

## 4. 档案插页（2篇，独立于正文，不占章号）

- **卷首**：清河登记簿残页——100-200字，横线/叉记号、涂改、对不上的数字（F12 物证）
- **卷尾**：撤离之夜调度单残页——100-200字（F15 物证）
- 规格：无叙事者评论；允许错字涂改；只呈现已知信息，不对剧情作新解释

## 5. 叙事者伦理自查清单（每章改完过一遍）

1. 有无"他终于明白""这意味着"式翻译句 → 删或换成具体动作
2. 主题词（货/定价/秤/人样）是否只出现在角色口中 → 叙事者段落清退
3. 有无旁白式设定讲解（"暴尸是游尸变异来的"类） → 删或换成角色认知
4. 有无"全场震惊"式围观镜头 → 删，留当事人自己的反应
5. 有无男频词汇（冷笑/嘴角/冷冽等，沈砺对白保留少数） → 清

## 6. 执行顺序

1. 档案插页2篇文案（独立、成本低，先做）
2. ch1 试改（信息灌入段压缩+东滩碎片——全书样板，同时确立压缩手感）
3. ch5-6（隔离救人案例+肩疤埋设）
4. ch10、ch19-21（闪回一二拍+情绪改写+反主题杂质）
5. 全卷通扫（叙事者伦理+词汇清理+压缩自查：每章按1.5节清单删钩子句/翻译句/围观镜头）
6. 并章衔接（压缩全部完成后最后做，按实际字数定稿章数与映射）
